# 电影购票系统 - 实施计划

## 项目现状

- ✅ 数据库 `end_of_term` 已建好（8张表 + 示例数据）
- ✅ Spring Boot 项目骨架已初始化（Maven + Java 17 + Spring Boot 4.0.6）
- ✅ 基础依赖已引入（MyBatis、MySQL Driver、Thymeleaf、Spring WebMVC）
- ❌ 无任何业务代码（Entity/Mapper/Service/Controller 均为空）
- ❌ 无前端项目
- ❌ 配置文件不完整（缺少数据库连接等关键配置）

---

## 实施步骤

### 第一步：完善后端基础配置

#### 1.1 配置 application.properties
- 数据库连接：MySQL 8.0，数据库名 `end_of_term`
- MyBatis 配置：驼峰映射、mapper-locations
- 服务器端口：8080
- 日志级别：DEBUG（开发阶段）

#### 1.2 添加缺失的 Maven 依赖
在 `pom.xml` 中补充以下依赖：
- **Lombok**：简化实体类代码
- **Knife4j**：API 接口文档（需求文档中提到 Swagger/Knife4j）

---

### 第二步：创建实体类（Entity）—— 8 张表

按照数据库表结构，创建对应的 Java 实体类，所有实体类放在 `com.example.end_of_term.entity` 包下：

| 序号 | 实体类 | 对应表 | 说明 |
|------|--------|--------|------|
| 1 | `User` | user | 用户表（含角色字段） |
| 2 | `Cinema` | cinema | 影院表 |
| 3 | `Movie` | movie | 电影表 |
| 4 | `Hall` | hall | 影厅表（关联影院） |
| 5 | `Screening` | screening | 场次表（关联电影、影厅） |
| 6 | `Seat` | seat | 座位表（关联影厅） |
| 7 | `OrderTicket` | order_ticket | 订单主表（关联用户、场次） |
| 8 | `OrderSeat` | order_seat | 订单座位明细表（关联订单、座位） |

---

### 第三步：创建 Mapper 层

为每张表创建 MyBatis Mapper 接口和对应的 XML 映射文件：

- Mapper 接口放在 `com.example.end_of_term.mapper` 包下
- XML 映射文件放在 `resources/mapper/` 目录下
- 每个 Mapper 包含基础 CRUD 方法
- 复杂查询（如可选座位查询）编写自定义 SQL

---

### 第四步：创建统一响应类与全局异常处理

#### 4.1 Result 统一响应类
放在 `com.example.end_of_term.common` 包下，包含：
- `code`：状态码（200/400/500）
- `message`：提示信息
- `data`：返回数据
- 静态方法：`success()`、`error()`

#### 4.2 全局异常处理
放在 `com.example.end_of_term.common` 包下：
- `@RestControllerAdvice` 全局异常拦截
- 处理常见异常：参数校验、业务异常、系统异常

#### 4.3 CORS 跨域配置
放在 `com.example.end_of_term.config` 包下，允许前端跨域访问。

---

### 第五步：创建 Service 层（核心业务逻辑）

每个模块创建 Service 接口和 ServiceImpl 实现类，放在 `com.example.end_of_term.service` 包下：

| 优先级 | Service | 核心方法 |
|--------|---------|----------|
| P0 | `UserService` | 注册、登录（区分普通用户/管理员） |
| P0 | `MovieService` | 电影列表（支持按状态筛选）、电影详情 |
| P0 | `CinemaService` | 影院列表（支持按城市筛选）、影院详情 |
| P0 | `ScreeningService` | 按电影查场次、按影院查场次、按日期筛选 |
| P0 | `SeatService` | 查询某场次可选座位（排除已售/待支付） |
| P0 | `OrderService` | 创建订单（含事务、并发控制）、我的订单、取消订单、支付（模拟） |
| P1 | `HallService` | 影厅基础查询 |
| P2 | `AdminService` | 管理后台 CRUD（电影/影院/场次/影厅管理） |

**关键业务逻辑：**
- 查询可选座位：排除 `PENDING` 和 `PAID` 状态的订单座位
- 创建订单：开启事务 → 检查座位可用性 → 计算总价 → 插入订单 → 插入订单座位明细 → 提交
- 取消订单：仅允许 `PENDING` 状态 → 删除/标记订单及关联座位

---

### 第六步：创建 Controller 层（REST API）

所有 Controller 放在 `com.example.end_of_term.controller` 包下，API 前缀为 `/api`：

| 优先级 | Controller | 主要接口 |
|--------|------------|----------|
| P0 | `UserController` | `POST /api/user/register`、`POST /api/user/login` |
| P0 | `MovieController` | `GET /api/movie/list`（支持 `status` 参数）、`GET /api/movie/{id}` |
| P0 | `CinemaController` | `GET /api/cinema/list`（支持 `city` 参数）、`GET /api/cinema/{id}` |
| P0 | `ScreeningController` | `GET /api/screening/byMovie/{movieId}`、`GET /api/screening/{id}` |
| P0 | `SeatController` | `GET /api/seat/available/{screeningId}` |
| P0 | `OrderController` | `POST /api/order/create`、`GET /api/order/my`、`PUT /api/order/cancel/{orderId}`、`PUT /api/order/pay/{orderId}` |
| P2 | `AdminController` | 电影/影院/场次/影厅的增删改查 |

---

### 第七步：前端项目搭建与开发

#### 7.1 创建 Vue 项目
- 在 `frontend/` 目录下创建 Vue 3 项目
- 安装依赖：axios、vue-router、element-plus

#### 7.2 Axios 封装
- baseURL 配置
- 请求/响应拦截器

#### 7.3 路由配置
按照需求文档中的路由规划配置 Vue Router

#### 7.4 页面开发（按顺序）
1. 电影列表页（热映/即将上映切换）
2. 场次列表页（按电影展示场次）
3. 座位选择页（可视化选座，核心页面）
4. 订单确认页
5. 我的订单页
6. 管理后台（简易 CRUD）

---

### 第八步：测试与验证

- 使用 Postman/Apifox 测试所有后端 API
- 前后端联调，验证完整业务流程
- 验证并发选座的正确性

    ↓

    ↓

    ↓

    ↓
